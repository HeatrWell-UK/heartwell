# Heartwell's Facebook Page

The owner is turning an older furniture Page of theirs (about 290 followers) into Heartwell's Page (16 October 2026). The followers, posts and reels stay; the name, look and details change. Most of it can be done now; the website link and the announcement wait for go-live (Phase 19), because until then every order on the site is a test order and customer emails go to the owner, not the customer.

Everything below is done in Facebook on a computer (facebook.com), switched into the Page: your profile picture → **See all profiles** → the Page. You need full control of the Page. Meta asks for your password for some changes: type it yourself.

## Do now

### 1. Name (first, because Meta reviews it)

**Settings and privacy → Settings → Page setup → Name → Edit** → **Heartwell Sofa** → Review change → Request change.

- Why "Heartwell Sofa": it's the logo ("Heartwell" over "SOFA") and the web address (heartwellsofa.co.uk). "Heartwell" alone also works, but Meta doesn't allow a Page name that's a single generic word, and other businesses use Heartwell.
- Meta reviews the change: minutes to about three days. Once it's changed you can't change it again for a while, so check the spelling.
- Meta's rules: the name must say who the Page is; no slogans, no "Official", no symbols ([Meta's Page name guidelines](https://www.facebook.com/help/519912414718764)).

### 2. Username

**Settings → Page setup → Username** → **heartwellsofa** (matches the web address and the Gmail). If it's taken: heartwellsofa.uk.
The Page then lives at facebook.com/heartwellsofa, which is the link to give out and to put on the website.

### 3. Profile picture and cover photo

- Profile picture: `design/social/heartwell-profile-with-name.png` (1080 × 1080: the logo with the name, in a gold ring on wine). The version without the name, `heartwell-profile.png`, is for WhatsApp and Instagram, where the picture is tiny.
- Cover photo: `design/social/heartwell-facebook-cover.png` (1640 × 924: the room from the home page, "Choose it today. Pay when it's home."). Phones show all of it; computers crop a little off the top and bottom, which leaves the words and the sofa.

Changing them adds a post to the Page; that's fine, it shows followers the new look.

### 4. Intro (the line under the name, 101 characters at most)

### 6. Button

**Edit action button → Send WhatsApp message**, to 07848 477056. Facebook sends a code to that WhatsApp to link it. WhatsApp is where people already ask, and it keeps working after go-live.

### 7. Old posts and reels

Look through them once. **Archive** (not delete, so it can be undone) anything that:
- quotes a price Heartwell doesn't charge, or a sofa Heartwell doesn't sell (old prices that no longer apply are misleading under UK consumer law);
- links to the old website;
- shows another shop's name or phone number.

Keep posts and reels of furniture Heartwell does sell.

### 8. Who controls the Page

- **Settings → Page access**: make sure only people who should manage Heartwell have access; remove anyone else.
- In **Meta Business Suite** (business.facebook.com), put the Page in Heartwell's Business portfolio. The ads, the Pixel and the catalogue need it later (`docs/TRACKING-SETUP.md`).

### 9. Instagram (if there's an account)

Link it (**Settings → Linked accounts → Instagram**) and give it the same name, username, picture (without the name) and intro.
